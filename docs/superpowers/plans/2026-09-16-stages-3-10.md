## Approved specification

Owner approved stages 3–10 plus development/TestFlight stage unlock on 2026-09-16.
Stages 1–4 share the existing manual subtitle-shadowing flow. Stages 5–6 show
each sentence's first word while playing its full audio, with a subtitle toggle
above playback. Stages 7–8 combine the configured 2/3/4 source phrases into one
learning unit, played continuously from the original audio files in a native queue.
Owner clarification: do not merge/export files. Stages 9–10 combine both.
All member sentences retain their own first-word hints. Stages 11–16 stay unavailable.
App Store keeps predecessor-stage completion requirements; development and
TestFlight can select any implemented stage. Access never fabricates completions.

## Global Constraints

- Preserve existing 1/2 checkpoints, cycle confirmations, XP and completion history.
- A chunk is one phrase for playback, cycles, counters, progress, and resume position.
- No inter-member manual taps, phase changes, or artificial waiting. Final short
  remainder is its own chunk; the current flat package format has no section IDs.
- Freeze group size in a run's checkpoint. Settings changes apply to the next run,
  not a paused run. Persist and validate source-count/group-plan compatibility.
- Subtitle hiding must not leak translations or other full-text UI paths.
- No commits, push, upload, purchase, reset, or account/service mutation. DUO files
  and private device data must remain untracked. Preserve existing iOS 27 changes.
- Work in the existing native worktree on codex/stages-3-10, based on latest dev.
- Follow TDD with real behavior tests. No subagents from workers. Do not touch
  unrelated source or pre-existing Expo/plugin edits.

## Architecture

Shared core owns stage methods, learning-unit grouping, immutable run metadata,
restore/backup validation, and default-locked access. Native adapters own the
distribution signal and continuous offline playback of original files. Routes
and components consume these contracts; native Apple types stay outside core.
