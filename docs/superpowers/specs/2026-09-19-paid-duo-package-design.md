# #47 유료 DUO 패키지 연결 설계

상태: 문서와 직접 구현 승인됨(2026-09-19 후속 구현 요청).
기준: 최신 origin/dev의 dec5520. 기존 #52 로컬 커밋은 별도 브랜치에 보존합니다.

## 목표와 범위

구매한 사용자가 명시적으로 DUO를 다운로드하고, 560개 원본 학습 블록의
음원·번역을 기존 스테이지에서 오프라인으로 학습할 수 있도록 연결합니다.
기존 StoreKit 구매 처리, Apple-hosted 다운로드, 원자적 설치, 학습 플레이어를
재사용합니다. 무료 내부 테스트 경로, 기존 패키지 및 학습 기록은 유지합니다.

새 서버, Supabase, 분석 UI, 미구현 스테이지, 공개 출시와 실제 결제는 범위 밖입니다.
표지와 구문 데이터는 보존하되 구문 분석 기능은 추가하지 않습니다.
App Store Connect 설정 변경·콘텐츠 업로드·실기기 교체는 별도 승인이 필요합니다.

## 선택한 구조

유료 패키지 전용 접근 조정 계층을 기존 구매·다운로드·학습 경계에 연결합니다.
별도 다운로드 엔진을 복제하지 않고 기존 설치 엔진을 재사용합니다.
UI에서 버튼만 활성화하는 방식은 직접 경로 진입이나 비동기 권한 변경을
방어하지 못하므로 사용하지 않습니다.

세 상태는 독립적으로 유지합니다.

- 구매 권한: 검증된 소유 / 미소유 / 확인 불가.
- 배포 설정: 패키지·버전·StoreKit 상품·Apple 자산 매핑의 유효성.
- 로컬 자료: 없음 / 전송 중 / 검증 중 / 정상 설치 / 손상.

상품 ID는 기존 네이티브 설정을 사용합니다. 유료 패키지는 무료 테스트와 다른
안정적인 패키지 식별자를 사용하며, 무료 학습 기록을 유료 기록으로 자동 변환하지
않습니다. 실제 Apple 자산 식별자는 승인된 배포 설정으로만 공급합니다.
매핑이 없는 빌드는 명확한 준비 중 상태를 표시하고 다운로드를 허용하지 않습니다.

## 구매 권한과 오프라인 정책

- 네이티브 StoreKit 검증 결과만 권한의 근거입니다. JS 플래그, 설치 파일,
  CloudKit 계정이나 백업 내용은 권한을 부여하지 못합니다.
- 다운로드 시작·재시도, 설치 공개 직전, 학습 진입에서 현재 권한을 확인합니다.
  UI와 직접 학습 경로 모두 같은 접근 정책을 사용합니다.
- 권한 갱신 도중 이전 비동기 결과가 도착하면 세대 번호로 무효화합니다.
  다운로드 도중 확인된 권한 취소는 취소 처리하고, 늦은 완료 결과가 준비 완료나
  학습 허용 상태를 공개하지 못하게 합니다.
- 오프라인에서는 StoreKit이 기기에서 검증 가능한 유효 구매를 반환하고
  로컬 자료가 완전하면 학습을 허용합니다. 매 문장마다 네트워크를 요구하지 않습니다.
- 확인 불가/서명 검증 실패는 권한 취소와 구별하되 새 접근은 잠급니다.
  기존 자료와 학습 기록은 지우지 않고 다시 확인/구매 복원을 제공합니다.
- 실행 중 권한이 취소되거나 확인 불가로 변경되면 학습을 정지·저장하고
  추가 재생을 차단합니다. 실제 학습으로 확인되지 않은 XP는 지급하지 않습니다.
- 오프라인 상태에서 아직 전달되지 않은 환불을 즉시 알아내는 것은 보장하지 않습니다.
  환불 통지가 확인되면 접근은 차단하지만 파일과 학습 기록을 자동 삭제하지 않습니다.
- 자동 갱신은 강제 구매 복원을 호출하지 않습니다. 구매 복원은 사용자 명시 동작입니다.

## 패키지 준비와 검증

입력은 승인된 로컬 원본 5종(음원 ZIP, 표지, 정보, 본문, 구문)입니다.
원본을 수정하지 않고 별도 임시 디렉터리에서 준비합니다. 실제 파일 이름·형식은
구현 시 해당 원본의 구조를 확인하며, 개인 콘텐츠를 로그나 테스트 fixture에 복사하지 않습니다.

- 정보와 본문의 560개 블록 및 45개 구역, 560개 음원의 대응을 확인합니다.
  대화형 블록은 하나의 원본 음원 단위로 유지합니다.
- 원본 5종의 크기·SHA-256과 변환 산출물의 크기·SHA-256을 manifest에 기록합니다.
  표지·정보·본문·구문 원본은 패키지에 보존하고, 음원 ZIP은 원본 지문을 보존한 뒤
  기존 학습용 개별 음원으로 변환해 배포합니다. 중복 ZIP 배포는 하지 않습니다.
- ZIP은 추출 전에 중앙 디렉터리와 실제 읽기 결과를 검증합니다. 경로 순회,
  절대 경로, 중복/정규화 충돌, 심볼릭 링크, 암호화·지원하지 않는 형식,
  선언 크기 불일치와 예상 외 항목을 거부합니다. 알려진 macOS 메타데이터만 제외합니다.
- 제한은 파일당 해제 50 MB, 전체 해제 1 GB, 메타데이터 파일당 20 MB,
  압축 비율 200:1, ZIP 항목 수 2,000개입니다. 실제 출력 바이트에도 제한을 적용합니다.
  원본이 제한을 넘으면 자동 완화하지 않고 중단·보고합니다.
- 원본 파일의 심볼릭 링크도 거부합니다. 준비 실패 시 소유한 임시 경로만 정리하고
  기존 준비 버전·원본·다른 패키지는 건드리지 않습니다.
- 버전별 결과와 자산 매핑은 불변입니다. 기존 버전에 다른 지문을 덮어쓰지 않습니다.
  동일 입력/도구 설정의 논리적 manifest와 파일 매핑 재현성을 검증하며,
  Apple 아카이브 파일의 바이트 단위 동일성은 별도로 입증하지 않으면 보장하지 않습니다.

앱 설치 엔진에는 고정된 추가 메타데이터 파일 허용 목록을 확장합니다.
임의 파일 경로는 허용하지 않습니다. 음원뿐 아니라 전체 필수 파일 검증이 끝나야
원자적으로 설치 완료 상태를 공개합니다. 변조·부분 설치는 재생할 수 없습니다.

## 라이브러리와 학습 연결

구매 카드와 유료 학습 도서를 하나의 상품/패키지 매핑으로 연결합니다.
미구매 상태는 구매, 소유·미설치는 다운로드, 소유·검증 완료는 학습을 제공합니다.
가격 및 상품명은 StoreKit 현지화 정보를 사용합니다. 자료 검증에 실패하면
재다운로드를 안내하되 구매를 다시 요구하지 않습니다.

학습 카탈로그·설치 확인·음원 경로·자료 삭제 경계를 유료 패키지에도 적용합니다.
직접 route로 들어가도 구매 및 설치 검증을 우회할 수 없습니다.
패키지/버전별 기존 LearningContext와 SQLite 저장 규칙을 유지합니다.
번역, 음원 위치, 확인된 사이클·XP는 보존하며 복원으로 보상을 추가하지 않습니다.
호환되지 않는 버전의 체크포인트를 새 내용에 적용하지 않습니다.
자료 삭제는 접근 권한이 없어도 명시적으로 가능하되 학습 기록이나 구매 내역은 보존합니다.

## 실패 처리와 보호 한계

구매 확인 불가, 다운로드 실패, 저장 공간 부족, 패키지 손상은 구분 가능한
안내와 재시도를 제공합니다. 자료 검증·권한 확인 전 성공을 표시하지 않습니다.
일상적인 저장·동기화·권한 갱신은 조용히 처리합니다.

이 설계는 정상 앱의 접근 제어이며 강한 DRM을 주장하지 않습니다.
Apple 자산 호스팅 자체가 구매 권한을 부여하거나 제3자의 복사를 방지한다는
가정은 하지 않습니다. 로컬 콘텐츠 기밀성·암호화 서버는 이번 범위가 아닙니다.

## 검증 및 인수 기준

실패 테스트를 먼저 추가하고 다음 경계를 검증합니다.

1. 구매/미구매/확인 불가/취소/환불과 전송 중 권한 변경, 늦은 완료 응답.
2. 오프라인 유효 구매와 설치의 조합, 직접 학습 route, 실행 중 접근 차단.
3. 원본 수량 불일치, ZIP 경로·중복·링크·크기·확장 제한, 누락 메타데이터.
4. 전체 검증 전 재생 불가, 실패 시 기존 유효 버전 보존, 안전한 재시도.
5. 무료 테스트·샘플 회귀, 유료 학습 재개 시 위치·사이클·XP 유지.
6. 타입 검사, 전체 도메인 회귀, StoreKit/배포 네이티브 테스트와 iOS 빌드.

자동 테스트는 합성 콘텐츠와 Apple 테스트 도구를 사용합니다. 실제 DUO 검증은
명시적으로 제공된 로컬 입력만 사용하고 공개 fixture/커밋에 넣지 않습니다.
실기기 sandbox·TestFlight·Apple-hosted 통합 증거는 #61에 별도 기록합니다.
#45의 계약/상품 설정이 미완료여도 로컬 구현과 테스트는 진행할 수 있지만,
그 결과를 실제 구매 성공이나 #47 전체 인수 완료로 보고하지 않습니다.

## 작업·배포 경계

새 codex/47-paid-package 브랜치는 최신 dev에서 시작합니다.
기존 #52 커밋은 원래 브랜치에 보존하고 자동 병합하지 않습니다.
DUO 원본·산출물은 ignored private 경로 밖으로 복사하지 않습니다.
현재 요청은 코드 구현이며, 커밋·푸시·PR·Apple 업로드·출시는 별도 요청에 따릅니다.

## 문서 자체 검토

- 소유권, 배포 설정, 로컬 준비 상태를 분리했습니다.
- 오프라인 허용과 확인 불가 차단, 환불 처리 한계를 명시했습니다.
- 무료 테스트 기록 보존과 유료 패키지 별도 식별자를 명시했습니다.
- 원본 보존과 배포 산출물의 차이, 구문 UI 제외 범위를 명시했습니다.
- 로컬 자동 검증과 #61 실기기 인수를 구분했습니다.
